INSTALLATION (Vollständiges Backend):
================================================================================

1. Datei wählen:
   patschi-backend-complete.html

2. In Texteditor öffnen und Supabase-Credentials eintragen:
   Zeile 17-18:
   const SUPABASE_URL = 'ihre-url';
   const SUPABASE_ANON_KEY = 'ihr-key';

3. Auf Webserver hochladen:
   - Via FTP/SFTP
   - Via Hosting-Panel
   - Via Git

4. Im Browser öffnen:
   https://ihre-domain.com/patschi-backend-complete.html

5. Anmelden und loslegen!
