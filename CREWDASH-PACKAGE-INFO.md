## 🚀 Quick Start

### Step 1: Extract (if using ZIP)
```bash
unzip crewdash-final.zip
cd crewdash-final
```

### Step 2: Configure
Open `index.html` in text editor and update line 90-91:
```javascript
window.VITE_SUPABASE_URL = 'https://YOUR-PROJECT.supabase.co';
window.VITE_SUPABASE_ANON_KEY = 'YOUR-ANON-KEY';
```

### Step 3: Upload
Upload entire `crewdash-final` folder to your web server:
- Via FTP (FileZilla, etc.)
- Via cPanel File Manager
- Via hosting control panel

### Step 4: Access
Navigate to:
```
https://your-domain.com/crewdash-final/index.html
```
