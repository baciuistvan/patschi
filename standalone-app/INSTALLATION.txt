QUICK INSTALLATION (5 MINUTES):
====================================================================

1. UPLOAD FILES TO YOUR WEB SERVER
   - index.html (main app)
   - admin.html
   - reservation-widget.html
   - assets/ folder (JavaScript & CSS)

2. SETUP SUPABASE (FREE ACCOUNT)
   - Go to supabase.com and create account
   - Create new project "apres-ski-system"
   - Get URL and anon key from Settings > API

3. CONFIGURE APP
   - Open index.html in browser
   - Follow setup wizard
   - Enter Supabase URL and key

4. RUN DATABASE MIGRATIONS
   - In Supabase, go to SQL Editor
   - Run each file in migrations/ folder (in order by date)

5. CREATE ADMIN USER
   - Sign up in the application
   - In Supabase SQL Editor, run:

   INSERT INTO admin_users (user_id, email, role)
   VALUES ('your-user-id', 'your-email@example.com', 'admin');

6. LOGIN AND USE!
   - Login with your email/password
   - System is ready to use
