📊 DATABASE SCHEMA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Tables Created:
  • admin_users - Staff access control (id, email, full_name, role)
  • rooms - Dining areas (id, name, description, is_active)
  • tables - Individual tables with positioning (id, room_id, table_number, 
    capacity, position_x, position_y, width, height, shape, is_active)
  • reservations - Customer bookings (id, table_id, customer_name, 
    customer_email, customer_phone, party_size, reservation_date, 
    reservation_time, duration_minutes, status, special_requests, 
    payment_status, payment_amount, stripe_payment_intent_id)

Security:
  • RLS enabled on all tables
  • Admin-only operations for sensitive data
  • Public reservations via secure Edge Function
  • JWT authentication required for admin

  • Admin Dashboard: http://localhost:5173/

  • Copy wordpress-integration.php to plugins folder
  • Activate plugin
  • Add widget or use shortcode
