SYSTEM REQUIREMENTS
-------------------
Server:
• Web server (Apache, Nginx, IIS, etc.)
• 10MB minimum storage
• SSL certificate (HTTPS recommended)
• No server-side processing required

Database:
• Supabase account and project
• Required tables:
  - rooms (restaurant areas)
  - tables (table configurations)
  - reservations (booking records)
  - gift_cards (gift card data)
• RLS policies for public read access

Client:
• Modern web browser:
  - Safari 12+ (iOS/iPadOS/macOS)
  - Chrome 80+
  - Firefox 75+
  - Edge 80+
• JavaScript enabled
• Internet connection
• Minimum 1024x768 resolution
