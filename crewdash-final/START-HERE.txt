🚀 QUICK START (3 STEPS)
------------------------

STEP 1: Configure (1 minute)
   • Open index.html in text editor
   • Find line 90-91
   • Update with your Supabase URL and API key:
     window.VITE_SUPABASE_URL = 'https://your-project.supabase.co';
     window.VITE_SUPABASE_ANON_KEY = 'your-anon-key';
   • Save file

STEP 2: Upload (2 minutes)
   • Upload ALL files to your web server
   • Keep folder structure intact (especially assets/ folder)
   • Use FTP, cPanel File Manager, or your preferred method

STEP 3: Access (30 seconds)
   • Open: https://your-domain.com/path-to-dashboard/index.html
   • Verify floor plan, calendar, and reservations load
   • Done!

📱 OPTIONAL: Add to iPad Home Screen
   • Open dashboard in Safari on iPad
   • Tap Share button → Add to Home Screen
   • Launch as full-screen app
