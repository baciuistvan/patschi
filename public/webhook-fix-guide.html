🔧 Fix Webhook Signature Error

Your webhook is reaching the server but the signing secret is incorrect

❌ Error: Webhook signature verification failed

This means your webhook URL is correct, but the signing secret in Supabase doesn't match the one from Stripe.

1 Get Your Webhook Signing Secret from Stripe

Go to your Stripe webhook page:

Open Stripe Webhooks →
  • Find your webhook endpoint (the one with URL ending in /handle-payment-link-webhook)
  • Click on it to view details
  • Look for "Signing secret" section
  • Click "Reveal" or "Show" to see the secret
  • It will start with whsec_
  • Copy the ENTIRE secret (including whsec_)
💡 The signing secret is different for each webhook endpoint. Make sure you're copying from the correct endpoint!

2 Update Supabase Secrets

Go to your Supabase Edge Functions settings:

Open Supabase Secrets →
⚠️ Important: You need to add TWO secrets!

Secret #1: Webhook Signing Secret

  • Name: STRIPE_WEBHOOK_SECRET
  • Value: The secret you copied from Stripe (starts with whsec_)
STRIPE_WEBHOOK_SECRET = whsec_xxxxxxxxxxxxxxxxxxxxx

Secret #2: Stripe Secret Key

  • Name: STRIPE_SECRET_KEY
  • Value: Your Stripe secret key (starts with sk_live_ or sk_test_)
  • Get this from: Stripe API Keys
STRIPE_SECRET_KEY = sk_test_xxxxxxxxxxxxxxxxxxxxx
📌 How to add secrets in Supabase:
1. Scroll to "Secrets" section
2. Click "Add new secret"
3. Enter name and value
4. Click "Add secret"
5. Repeat for second secret

3 Test the Webhook

After updating the secrets, test immediately:

  • Go to your gift card purchase page
  • Make a test purchase (use Stripe test card: 4242 4242 4242 4242)
  • Check if gift card appears in your admin panel
  • Check if email is sent to recipient
✅ If successful, you'll see:
• Gift card created in database
• Email sent to recipient
• No more signature errors in Stripe webhook logs

4 Verify in Stripe Logs

Check that the webhook is now working:

View Webhook Logs →
  • Click on your webhook endpoint
  • Go to "Logs" or "Events" tab
  • Look for recent events
  • Status should be 200 Success
  • If you see red errors, the secret is still wrong

🔍 Common Issues & Solutions

Issue: Still getting signature error after updating secret
Solution:
  • Make sure you copied the ENTIRE secret including "whsec_"
  • No extra spaces before or after the secret
  • Try clicking "Reveal" again in Stripe to copy fresh
  • Edge functions may take 30 seconds to reload - wait and try again
Issue: Gift card created but no email sent
Solution:
  • Check SMTP settings in admin panel → Settings → Email
  • Use the gift card recovery page to resend emails
Issue: Where do I find sk_test or sk_live key?
Solution:
  • Go to Stripe Dashboard → API Keys
  • Copy "Secret key" (not Publishable key)
  • Use sk_test_ for testing, sk_live_ for production
