Steps to fix the 400 error:

  1. Go to Stripe Webhooks
  2. Click on your webhook endpoint
  3. Check the "Endpoint URL" matches the URL above
  4. In "Signing secret" section, click "Reveal" and copy the secret (starts with whsec_)
  5. Go to Supabase Dashboard → Edge Functions → Secrets
  6. Add or update secret:
    • Name: STRIPE_WEBHOOK_SECRET
    • Value: Your whsec_... secret from Stripe
  7. Click "Save"
  8. The function will automatically restart with new secrets
  9. Test webhook again in Stripe

Common Issues

400 Error: Webhook signature verification failed

The STRIPE_WEBHOOK_SECRET in Supabase doesn't match the signing secret shown in Stripe dashboard. Make sure you copied the ENTIRE secret including "whsec_"

Secret not taking effect

After adding/updating the secret in Supabase, you need to wait ~30 seconds for the function to restart. Try the test webhook again after waiting.

Wrong webhook URL

The endpoint URL in Stripe must be EXACTLY: https://YOUR_PROJECT.supabase.co/functions/v1/handle-payment-link-webhook

Events to listen for

Make sure your webhook is listening to: checkout.session.completed

Check Supabase Logs

To see what's happening in your webhook function:

  1. Go to Supabase Dashboard → Edge Functions
  2. Click on "handle-payment-link-webhook"
  3. Click "Logs" tab
  4. Send a test webhook from Stripe
  5. Watch the logs - you'll see exactly what's happening
