3. Webhook Configuration Check Required

Your Stripe webhook must be configured correctly.

Required Webhook URL:
https://qwwerwkekvmaswusvgxy.supabase.co/functions/v1/handle-payment-link-webhook

Steps to Fix Webhook 404 Error:

  1. Go to Stripe Dashboard → Webhooks
  2. Click on your webhook endpoint (or create a new one)
  3. Set the endpoint URL to the URL shown above
  4. Make sure checkout.session.completed event is selected
  5. Copy the Signing secret (starts with whsec_...)
  6. Go to Supabase Edge Function Secrets
  7. Add secret: Name = STRIPE_WEBHOOK_SECRET, Value = your signing secret
  8. Add secret: Name = STRIPE_SECRET_KEY, Value = your Stripe secret key (sk_live_...)
