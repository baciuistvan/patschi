PATSCHI CREW DASHBOARD - STANDALONE VERSION
===========================================

This is a fully functional standalone version of the Patschi Crew Dashboard that you can upload to any web hosting.

REQUIREMENTS:
-------------
- A Supabase account with your database set up
- A web server that can serve HTML files (any hosting provider)

INSTALLATION:
-------------
1. Upload ALL files and folders to your web hosting
   - crew.html
   - crew-icon-180.png
   - crew-icon-512.png
   - assets/ (entire folder with all files)

2. The file structure should look like this on your server:
   your-domain.com/
   ├── crew.html
   ├── crew-icon-180.png
   ├── crew-icon-512.png
   └── assets/
       ├── main-BlIeDAjW.js
       ├── main-CQhF2cm_.css
       ├── html2canvas.esm-CBrSDip1.js
       ├── purify.es-B9ZVCkUG.js
       └── index.es-COVPnJs1.js

3. Access the crew dashboard at:
   https://your-domain.com/crew.html

ADDING TO IPAD HOME SCREEN:
----------------------------
1. Open crew.html in Safari on your iPad
2. Tap the Share button
3. Tap "Add to Home Screen"
4. The app will appear with a blue icon with a white "P"

NOTES:
------
- All assets are already compiled and optimized
- Dark theme optimized for iPad viewing
- The app connects to your existing Supabase database
- No additional configuration needed if your database is already set up
- Works offline once loaded (PWA capable)
- Split-screen layout: floor plan on left, bookings on right
- Gift card verification in header

SUPPORT:
--------
Make sure your Supabase project URL and keys are properly configured in your main application settings.
